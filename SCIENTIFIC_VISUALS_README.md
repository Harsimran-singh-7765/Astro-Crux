# Scientific Visuals Module - Implementation Guide

## Overview

The **Scientific Visuals** module integrates astronomical calculations with AI-driven visualization to create a dynamic Vedic Chart that highlights relevant houses during conversation.

### Architecture

```
User Input (Voice)
    ↓
[STT] → Speech Recognition
    ↓
[LLM] → AI Response with Focus Signals [FOCUS:HOUSE_7]
    ↓
[Extract Signal] → Parse [FOCUS:HOUSE_X] tag
    ↓
[Clean Text] → Remove tags for TTS
    ↓
[Frontend] → Display chart + highlight house
    ↓
[TTS] → Audio playback
```

## Components

### 1. **Backend: Vedic Calculator** (`app/services/vedic_calculator.py`)

Calculates mathematically accurate Vedic astrology positions using Skyfield ephemeris data.

#### Key Features
- **Lahiri Ayanamsa**: Precession shift calculation (accurate 1900-2100)
- **Tropical → Sidereal Conversion**: Converts Skyfield tropical positions to Vedic sidereal
- **Ascendant (Lagna)**: Calculated via Greenwich Sidereal Time
- **Equal House System**: 12 houses of 30° each
- **Planet Positions**: Sun, Moon, Mercury, Venus, Mars, Jupiter, Saturn

#### Function: `calculate_vedic_chart(birth_datetime, latitude, longitude, timezone_str)`

**Input:**
```python
birth_dt = datetime(2000, 1, 1, 12, 0)
lat, lon, tz = 28.6139, 77.2090, 'Asia/Kolkata'
chart = calculate_vedic_chart(birth_dt, lat, lon, tz)
```

### 2. **Backend: LLM Service Signals** (`app/services/llm_service.py`)

Extracts focus signals from LLM responses to indicate which house the AI is discussing.

#### New Functions

**`extract_focus_signal(response_text: str) -> str`**
- Regex pattern: `\[FOCUS:([A-Z_0-9]+)\]`
- Returns: `"HOUSE_7"`, `"PLANET_MARS"`, or `""` (if none found)
- Example: `"[FOCUS:HOUSE_7] Your relationships..."` → `"HOUSE_7"`

**`clean_response_text(response_text: str) -> str`**
- Removes all `[FOCUS:...]` tags before TTS
- Ensures audio doesn't include artifact sounds
- Example: `"[FOCUS:HOUSE_7] Your relationships..."` → `"Your relationships..."`

#### System Prompt Enhancement
The LLM is instructed to embed focus tags in responses:
```
When discussing specific houses or planets, include a focus signal:
- [FOCUS:HOUSE_1] for House 1 (Self)
- [FOCUS:HOUSE_7] for House 7 (Relationships)
- [FOCUS:PLANET_MARS] for Mars discussions
```

### 3. **Backend: Game Session Manager** (`app/services/game_session_manager.py`)

Orchestrates the entire session flow with signal extraction and WebSocket communication.

#### Key Changes

1. **Send Chart Data on Session Start**
```python
if self.session.chart_data:
    await self._send_json({"status": "chart_data", "chart": self.session.chart_data})
```

2. **Extract and Send Focus Signal**
```python
response = get_astro_response(self.session)

# Extract focus signal BEFORE cleaning
focus_signal = extract_focus_signal(response)
if focus_signal:
    await self._send_json({"status": "ai_focus", "focus": focus_signal})

# Clean response for TTS (removes focus tags)
clean_response = clean_response_text(response)

# Send clean text and audio
await self._send_json({"status": "ai_response_text", "text": clean_response})
await self._stream_ai_audio(clean_response)
```

#### WebSocket Messages

**Chart Data Message:**
```json
{
  "status": "chart_data",
  "chart": {
    "meta": {...},
    "ascendant": {...},
    "planets": {...},
    "houses": {...}
  }
}
```

**Focus Signal Message:**
```json
{
  "status": "ai_focus",
  "focus": "HOUSE_7"
}
```

### 4. **Frontend: SVG Kundli Chart** (`testing/index.html` + CSS)

Responsive North Indian (Diamond) Kundli chart with dynamic highlighting.

#### SVG Structure
```html
<svg id="kundliChart" viewBox="0 0 400 400" class="kundli-svg">
  <!-- 12 house polygons (generated by JavaScript) -->
  <polygon id="house-1" class="house-polygon" points="200,200 350,200 275,100"></polygon>
  <polygon id="house-2" class="house-polygon" points="200,200 350,200 275,100"></polygon>
  <!-- ... house 3-12 -->
  
  <!-- House labels (H1, H2, etc.) -->
  <text class="house-text" x="275" y="110">H1</text>
  <!-- ... -->
  
  <!-- Planet names (Sun, Moon, Mars, etc.) -->
  <text class="planet-text" data-planet="sun" data-house="1">SU</text>
  <text class="planet-text" data-planet="mars" data-house="7">MA</text>
  <!-- ... -->
  
  <!-- Ascendant label -->
  <text class="ascendant-text" x="170" y="40">ASC: Sagittarius</text>
</svg>
```

#### CSS Classes

**`.house-polygon`** - Base styling
- Stroke: Accent color (purple/violet)
- Fill: 15% opacity purple
- Cursor: pointer
- Smooth transitions

**`.house-polygon.active-glow`** - Active state
- Fill: 30% opacity gold
- Stroke: Gold color
- Glow effect via drop-shadow filter
- Triggers animation

**`@keyframes houseGlow`** - Highlight animation
```css
@keyframes houseGlow {
  0% {
    filter: drop-shadow(0 0 0px rgba(251, 191, 36, 0));
  }
  100% {
    filter: drop-shadow(0 0 15px rgba(251, 191, 36, 0.8));
  }
}
```

Duration: 0.6s, Timing: ease-out

### 5. **Frontend: Chart Drawing Logic** (`testing/script.js`)

JavaScript functions to render the SVG chart and handle highlighting.

#### Global Variable
```javascript
let chartData = null;  // Stores backend chart data
```

#### Main Functions

**`drawKundliChart(chart)`**
- Creates 12 triangular house polygons in diamond layout
- Calculates polygon vertices based on 30° angles
- Places house labels (H1, H2, ..., H12)
- Plots planet names in their correct houses
- Adds ascendant indicator at top
- Each house gets `id="house-N"` for CSS targeting

**`highlightHouse(houseNumber)`**
- Removes active glow from all other houses
- Adds `.active-glow` class to target house
- Logs action for debugging

**`removeHouseHighlight()`**
- Clears all active house highlights
- Used at end of focus period (4 seconds)

#### WebSocket Integration

In `handleJson(msg)`:
```javascript
else if (msg.status === "chart_data") {
    drawKundliChart(msg.chart);
}
else if (msg.status === "ai_focus") {
    const houseNum = parseInt(msg.focus.split("_")[1]);
    highlightHouse(houseNum);
    setTimeout(() => removeHouseHighlight(), 4000);
}
```

## Troubleshooting

### Issue: Chart Not Displaying
- Check browser console for errors
- Verify SVG element exists: `<svg id="kundliChart">`
- Ensure CSS is loaded: `.house-polygon` styles present

### Issue: Focus Signal Not Triggering
- Verify LLM response includes `[FOCUS:HOUSE_X]` tag
- Check backend logs for signal extraction
- Ensure WebSocket message includes `"status": "ai_focus"`

### Issue: Planet Not in House
- Verify ascendant calculation is correct
- Check planet longitudes are in 0-360° range
- Confirm house calculation formula: `(planet_lon - asc_lon) % 360 / 30 + 1`

### Issue: Animation Not Smooth
- Check CSS animations loaded
- Verify browser supports `@keyframes`
- Check for JavaScript errors in console
